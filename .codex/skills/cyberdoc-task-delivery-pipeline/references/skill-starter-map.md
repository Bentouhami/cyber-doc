# Skill Starter Map (CyberDoc)

Use this map to select the smallest effective skill set per job.

## Baseline for implementation tasks

1. `brainstorming` (mandatory before feature/behavior changes).
2. `cyberdoc-task-delivery-pipeline` (execution standard).
3. Add one domain skill + one quality skill.
